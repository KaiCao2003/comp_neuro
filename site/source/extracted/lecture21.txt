5.1 general 2×2 eigenvalues 与 integrator condition

【必要前置】      W=[[W11,W12],[W21,W22]] 何时有 eigenvalue 1？
                                       p
                            W11 + W22 ± (W11 − W22 )2 + 4W12 W21
                       λ± =
                                            2
                           det(I − W ) = (1 − W11 )(1 − W22 ) − W12 W21 = 0
1. 由 det(W−λI)=0 得 quadratic formula。
2. perfect integrator 要求 dominant λ+=1。
3. 直接令 λ=1 代入 characteristic polynomial 得 det(I−W)=0。
4. 这是一条 scalar constraint，四个 weights 中通常仍有三维 solution family（加入结构约束后减少）。

  Geometric/computational intuition. 功能约束的是某个 population mode 的 net feedback，而
  不是每条 synapse 的唯一值。
  Biological interpretation / failure condition. 另一 eigenvalue 必须稳定，且 nonlinear oper‑
  ating range/robustness 也需满足。

5.2 one‑parameter relation 的教学特例

【补全推导】      给定三项如何解第四项？
                                     (1 − W11 )(1 − W22 )
                             W21 =                              (W12 ̸= 0)
                                            W12

1. 从 det(I−W)=0 隔离 W21。
2. 若 W12=0，不能除；此时需 (1−W11)(1−W22)=0，即至少一个 self‑weight 为 1。
3. 正/负 signs 还受 excitatory/inhibitory architecture 限制。
4. 同一 integration time scale 可由许多 combinations 达到。

  Geometric/computational intuition. 这是 parameter compensation：一项变强可由另一项变
  弱抵消。
  Biological interpretation / failure condition. 只满足 algebraic eigenvalue 不保证 biological
  conductances/units 合法。

1. 每个 eye position p_μ 提供一组 neuron rates。
2. 把 presynaptic excitatory/inhibitory nonlinearities 评估后放入 design X。
3. postsynaptic inverse F–I 给 target current Y。
4. 对每个 output neuron 独立做 least squares，weights 与 bias 是线性参数。

  Geometric/computational intuition. 模型整体有 nonlinear components，但一旦这些 compo‑
  nents 固定，剩余 weight fitting 可 linear。

  noise 结构复杂，problem 不再是简单 OLS。

1. H 的 eigenvector 是 parameter‑space direction，不是 neural activity mode。
2. 大 λ direction 小变化即显著恶化 fit，称 stiff。
3. 小 λ direction 可大幅变化而 loss 变化小，称 sloppy。
4. 笔记实例中约 4 个 stiff、46 个 sloppy dimensions，说明 many adequate models。

  Geometric/computational intuition. elongated error valley 表示参数可互相补偿。
  Biological interpretation / failure condition. sloppy 不等于参数生物上不重要；可能只是当前
  数据/experiment 不敏感。

6 Cross‑page synthesis / 跨页因果与数学链

  oculomotor integrator 需要在 saccade 后保持 eye position，因此 network 必须产生接近 λ=1 的
  long‑timescale mode。对 general 2×2 W，perfect integration 只约束 det(I−W)=0，留下 many‑to‑
  one 的 weight family；复杂 biological models 中这种 parameter degeneracy 更强。把 measured
  tuning 与 synaptic nonlinearities 固定后，fitting 可重写为 linear regression；Hessian eigen‑
  values 区分少数 stiff combinations 与大量 sloppy combinations，支持分析 adequate‑model
  ensemble 而非唯一 best fit。

10 Common traps, assumptions, and limitations

1. 把 eye position persistence 误认为 sensory afterimage，而非 velocity integration。
2. 只要求 λ=1，不检查其他 modes stability。
3. W12=0 时仍使用除法 family formula。
4. 把 many‑to‑one parameter mapping 当作 measurement noise。
5. 把 neural‑state low dimensionality 与 parameter‑space sloppiness 混淆。
6. 把 sloppy parameter 解释为生物学上无关。
7. 只报告 best‑fit weights，不报告 uncertainty/ensemble。

  Course‑specific risk boundary. 清 楚 区 分 neural‑state low dimensionality 与 parameter‑
  space sloppiness；它们是不同空间中的不同概念。
