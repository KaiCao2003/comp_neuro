5 补全推导与数学支架 / Derivations

5.1 linear two‑neuron complex modes

【必要前置】      分析 W=[[0,−w0],[w0,0]]。
                                          λ± = ±i|w0 |
                                     τ α̇± = −(1 ∓ i|w0 |)α±
                                 α± (t) = α± (0)e−t/τ e±i|w0 |t/τ
1. characteristic polynomial λ²+w0²=0。
2. network ODE 还有 intrinsic −I term，所以 full mode exponent real part 为 −1/τ。
3. Euler identity 把 complex exponential 分成 sine/cosine。
4. amplitude e^{‑t/τ} 衰减，因此不是 sustained oscillator。

  Geometric/computational intuition. imaginary part 给 angular frequency，real part 给 en‑
  velope decay/growth。
  Biological interpretation / failure condition. 看到 complex eigenvalues 就断言 limit cycle，
  是线性/非线性混淆。

5.2 Morris–Lecar fast–slow equations

【补全推导】      用两个 variables 描述 intrinsic bursting/spiking geometry。

                  C V̇ = −gL (V − EL ) − ḡCa M∞ (V )(V − ECa ) − ḡK N (V − EK ) + I

                                         τN Ṅ = N∞ (V ) − N
1. V 是 fast voltage，N 是 slower K activation/recovery。
2. V‑nullcline 由 dV/dt=0，常呈 cubic/N shape；N‑nullcline 为 N=N∞(V)。
3. intersection 是 fixed point，其 stability 决定 resting vs oscillatory regime。
4. fast–slow separation 让 trajectory 沿 stable branches 慢走，在 fold 附近快跳。

  Geometric/computational intuition. relaxation oscillator 在慢积累与快 transition 之间循环。
  Biological interpretation / failure condition. 具体 nullcline shapes/parameters 不同会改变
  bifurcation 与 oscillation type。

5.3 relaxation cycle 四阶段

【跨页连接】      按 phase‑plane 解释 autonomous oscillation。

                                    V̇ = F (V, N ),   Ṅ = G(V, N )

1. lower branch 上 N 下降或缓慢变化，V 低。
2. 达到 fold 后 fast V 跳到 upper branch。
3. upper branch 上 N 增加，K current 增强。
4. 达到另一 fold 后 V 快速回到 lower branch，cycle 重复。

  Geometric/computational intuition. 一条变量慢慢改变系统的 instantaneous equilibrium，最
  终触发快速 jump。
  Biological interpretation / failure condition. phase‑plane arrows 必须由 F/G signs 判断，不
  能仅按图形顺时针猜。

5.4 half‑center release 与 escape

【模型边界】      互抑 neurons 如何轮流 active？

                                Isyn = −ḡs S∞ (Vpre )(V − Es )

                                    S∞ (V ) ≈ H(V − VT )
1. active neuron 超过 V_T，强抑制另一 neuron。
2. release：active neuron 的 intrinsic adaptation 使其离开 upper branch/停止，解除对 partner 抑制。
3. escape：inhibited neuron 的 intrinsic recovery 使其越过 lower‑branch threshold，即使 inhibition
   仍存在也跳出。
4. 两者可通过相位图中由哪一个 cell 的 intrinsic transition 先发生来区分。

  Geometric/computational intuition. 交替可由“发放者放手”或“被抑制者逃脱”启动。
  Biological interpretation / failure condition. 实际 circuits 可能混合 release/escape、sensory
  feedback 与 neuromodulation。

6 Cross‑page synthesis / 跨页因果与数学链

  阻断 synapses 后 rhythm 是否保留，可区分 intrinsic pacemaker 与 network‑generated rhythm
  的候选机制。线性 two‑neuron complex eigenvalues 只产生 damped 或 growing oscillatory com‑
  ponents；稳定的 autonomous limit cycle 需要 nonlinearity。Morris–Lecar 的 fast voltage/slow
  recovery nullclines 产生 relaxation oscillation；互抑 half‑center 可通过 intrinsic release 或
  escape 交替。

10 Common traps, assumptions, and limitations

1. 所有 rhythmic activity 都称 CPG。
2. complex eigenvalues 自动等于 sustained oscillation。
3. 忽略 full eigenvalue 的 real part。
4. nullcline 当作 trajectory。
5. fixed point intersection 存在就认为 stable。
6. release 与 escape 只按表面 firing order 区分，而不看哪个 intrinsic transition 触发 switch。
7. 把 sensory feedback 排除在真实 locomotor rhythm 外。

  Course‑specific risk boundary. 不要把所有 rhythmic activity 都归为 CPG，也不要把 damped
  linear oscillation 与 autonomous nonlinear oscillator 混为一谈。
