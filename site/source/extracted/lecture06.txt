5.1 Poisson count 的 mean、variance 与 Fano factor

【必要前置】      给定 rate r、窗口 T，spike count k 如何波动？

                                                 k!

                                             Var(K)

1. λ 是期望 count，不是 instantaneous voltage。
2. 利用概率生成函数或标准求和可得 first/second moments。
3. variance=mean 导致 Fano factor 1。
4. 实验中的 F≈1 只支持 Poisson‑like count variability，不证明所有 point‑process assumptions。

  Geometric/computational intuition. Poisson 中每个小 bin 都提供独立、稀少的 spike oppor‑
  tunity，波动随平均数一起增大。
  Biological interpretation / failure condition. refractory、bursting、rate drift、trial corre‑
  lations 会使 Fano/CV 偏离 1。

5.2 ISI distribution 与 homogeneous point process

【补全推导】      若 rate 恒定且 independent increments，等待下一 spike 多久？

                               P (TISI > t) = P (N (t) = 0) = e−rt

                                        fISI (t) = re−rt
                                   E[TISI ] = SD(TISI ) = 1/r
1. 等待时间大于 t 等价于长度 t 的窗口内没有 spike。
2. Poisson zero‑count probability 是 e^{‑rt}。
3. 对 survival function 求负导数得到 exponential density。
4. CV=SD/mean=1。

  Geometric/computational intuition. exponential 的 memoryless property 表示已经等多久不
  改变下一瞬间 hazard。
  Biological interpretation / failure condition. absolute refractory 使短 ISI 缺失，regular spik‑
  ing 使 CV<1，bursting 可使 CV>1。

6 Cross‑page synthesis / 跨页因果与数学链

  神经编码不是只画 tuning curve，而是指定 stimulus 条件下完整 response distribution。Poisson
  model 同时预测 count variance≈mean、exponential ISI 与 independent increments；这些是
  可检验假设而非普遍事实。population likelihood 把各 neurons 的 evidence 相乘，log‑likelihood
  将乘积化为求和；curvature 则连接解码精度与 Fisher information。

10 Common traps, assumptions, and limitations

1. 把 firing rate 当作电极直接测得的连续信号。
2. 把 raster、count、PSTH 和 rate 混为同一对象。
3. Fano≈1 就断言 spike train 完全 Poisson。
4. 忽略观察窗 T，使 rate 与 count 的单位混乱。
5. 把 P(n|s) 与 P(s|n) 写反。
6. 在 population likelihood 中默认 independence 而不说明。
