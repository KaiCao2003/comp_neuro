6 补全推导与数学支架 / Derivations

6.1 separation of variables：指数增长

【必要前置】      求 dx/dt=x, x(0)=x0。
                                      dx
                                          = dt
                                       x
                                       x(t)
                                    ln      =t
                                         x0
                                    x(t) = x0 et
1. 把所有 x 项移到左边、t 项移到右边。
2. 从初始状态 x0 积分到 x(t)，避免遗漏积分常数。
3. 指数化并用 x(0)=x0 验证。
4. 代回原式：d(x0e^t)/dt=x0e^t=x(t)。

  Geometric/computational intuition. 变化率与当前量成比例，所以每个相同时间间隔都乘以相同
  因子。
  Biological interpretation / failure condition. 若 x 穿过 0，直接除以 x 需要分段讨论；初值 x0=0
  的解恒为 0。

6.2 常输入一阶系统的解析解

【补全推导】      求 τ dx/dt=−x+I，I 为常数。
                                               dx
                                           τ      = −(x − I)
                                               dt

                          x(t) = I + (x0 − I)e−t/τ = x0 e−t/τ + (1 − e−t/τ )I
1. 定义 gap z=x−I，则 τ dz/dt=−z。
2. 分离变量得到 z(t)=z(0)e^{‑t/τ}。
3. 代回 z(0)=x0−I。
4. t→∞ 时 x→I；t=τ 时初始 gap 剩 e^{‑1}≈0.37。

  Geometric/computational intuition. 系统并不是直接“复制”输入，而是以 time constant τ 低
  通追踪 steady state。
  Biological interpretation / failure condition. I(t) 若随时间变化，常输入 closed form 不能直接
  代用，需要 convolution 或数值积分。

6.3 Euler update 与稳定性

【跨页连接】      把 dx/dt=f(x,t) 转成离散计算，并判断步长。

                              xn+1 = xn + ∆t f (xn , tn )
                                               
                                            ∆t
                                zn+1 = 1 −        zn
                                             τ
                                 ∆t            ∆t
                            1−      < 1 ⇐⇒ 0 <    <2
                                 τ             τ
1. 用前向差分 (x_{n+1}−x_n)/Δt 近似导数。
2. 右端必须在已知的 n 时刻求值，得到 explicit Euler。
3. 对衰减方程，误差每步乘以 1−Δt/τ。
4. 0<Δt/τ<1 单调衰减；1< 比值 <2 交替衰减；≥2 不衰减或发散。

  Geometric/computational intuition. Euler 用当前切线走一个小步；步太大时切线会越过目标并
  放大误差。
  Biological interpretation / failure condition. stiff system、快速门控或振荡系统可能需要更小
  步长或高阶/隐式 solver。

  Micro‑check
  Δt/τ=2.2 会怎样？

6.4 二阶 oscillator 改写为一阶系统

【模型边界】      把 d²x/dt²=−x 写成 state‑space form。

                                                  dx
                                             y=
                                                  dt
                                                
                                      d x      0 1 x
                                           =
                                      dt y    −1 0 y
                          x(t) = sin t,   y(t) = cos t   (x0 = 0, y0 = 1)
1. 把 velocity y 作为第二个状态。
2. 第一式定义 position 的变化；第二式由原二阶方程给出 velocity 的变化。
3. 在 phase plane 中 exact trajectory 是圆，能量 x²+y² 保持。
4. explicit Euler 的更新矩阵模长大于 1，因此代码会缓慢向外螺旋。

  Geometric/computational intuition. 高阶方程没有消失；它被展开成多个共同决定未来的一阶状
  态。
  Biological interpretation / failure condition. 误把 x(:,1)、x(:,2) 当作两个独立神经元，而不是
  同一 oscillator 的 position/velocity 状态。

  Micro‑check
  为什么右端使用 x_n 而不是 x_{n+1}？

7 Cross‑page synthesis / 跨页因果与数学链

  微分方程用局部变化率定义完整时间轨迹；初始条件选择具体解。解析解提供精确结构和极限检查，
  Euler method 则把导数定义改写为可迭代更新。数值结果是否可信取决于步长相对 time constant 的
  大小，而不只是代码是否运行。高阶方程可通过新增状态变量改写为一阶耦合系统，这是后续 network
  dynamics 的基础。

11 Common traps, assumptions, and limitations

1. 把导数当作有限时间段的总变化，而忘记它是 Δt→0 的瞬时变化率。
2. 求 separation solution 时遗漏初始条件或积分常数。
3. 认为代码能运行就意味着 Δt 足够小。
4. Euler 更新使用 I(t_n) 而不是未知的 I(t_{n+1})；索引错一位会改变算法。
5. 把 oscillatory exact dynamics 与 explicit Euler 的向外螺旋混为一谈。
6. 混淆 time constant τ 与模拟步长 Δt。

  Course‑specific risk boundary. 不要只解释代码语法。必须把每一行 MATLAB 与对应 differential
