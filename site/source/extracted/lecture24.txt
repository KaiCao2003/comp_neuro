5 补全推导与数学支架 / Derivations

5.1 reward‑baseline three‑factor rule

【必要前置】      为什么 Δw=pre×post×R 会 over‑strengthen？

                                      ∆w = η e(x, y)R

                                   ∆w = η e(x, y)(R − R̄)
                                    E[∆w] = η Cov(e, R)
1. eligibility/coactivity e 在行为与 reward 发生时为正。
2. 若 R 总为正，naive rule 平均持续 potentiates。
3. 减去 expected reward 使普通/已预测 reward 的 mean update 为零。
4. 只有 coactivity 与 above‑baseline reward 共变时净增强。

  Geometric/computational intuition. 学习的是“比预期好/坏”，而不是 reward 的绝对存在。
  Biological interpretation / failure condition. baseline 估计错误、delayed credit assignment
  与 nonstationary rewards 需更复杂 mechanisms。

5.2 matching condition

【补全推导】      stationary learning 如何导出 choice ratio≈reward ratio？

                                 E[∆w] = 0 ⇒ Cov(N, R) = 0

                                 E[R | C = A] = E[R | C = B]
                                          CA   RA
                                             ≈
                                          CB   RB
1. 假设 neural activity N 的 conditional mean 随 choice 改变。
2. covariance=0 可分解为 choice‑conditioned reward means 的差。
3. stationarity 要求两 choice 的 obtained reward rate 相等，否则权重继续改变。
4. 在 baiting/foraging assumptions 下，这等价于 choice fractions 匹配 reward fractions。

  Geometric/computational intuition. agent 重新分配 choices，直到两个 options 的 marginal
  return 相等。
  Biological interpretation / failure condition. matching law 依 task reward schedule、choice
  stochasticity 与 learning assumptions。

5.3 Rescorla–Wagner 与 blocking

【跨页连接】      cue weights 如何学习 immediate reward prediction？
                                         ∑
                                    V =    w i xi
                                              i

                                      ∆wi = ηxi (R − V )
1. squared prediction error 的 negative gradient 给 x_i(R−V)。
2. 未预测 reward 产生 positive error，active cue 增权。
3. 已由 cue S1 完全预测 reward 时，再加入 S2 有 R−V≈0。
4. 因此 S2 没有学习信号，产生 blocking。

  Geometric/computational intuition. 学习由 surprise/prediction error 驱动，而不是简单 stim‑
  ulus–reward coincidence。
  Biological interpretation / failure condition. configural representations、attention 与 non‑
  stationary associations 会改变 blocking。

5.4 TD error、temporal features 与 Q

【模型边界】      reward 延迟时如何把 credit 传回早期 cues/actions？

                                Gt = Rt+1 + γRt+2 + γ 2 Rt+3 + · · ·

                                      δt = Rt+1 + γVt+1 − Vt
                                  Q(s, a) = E[Gt | st = s, at = a]
1. γ 控制未来 reward discount。
2. TD error 比较当前 estimate 与 one‑step reward+next value bootstrap target。
3. temporal/state features 使 cue 的不同 time‑since‑onset 有不同 weights。
4. Q 将 value 条件化于 action，可支持 argmax action selection。

  Geometric/computational intuition. prediction error 从 reward 时刻向 predictor cue 转移。
  Biological interpretation / failure condition. partial observability、state representation 错
  误与 off‑policy issues 在下一课系统化。

   learned decisions 需要把 stimulus/action activity 与 delayed reward 联系起来。简单 reward‑

10 Common traps, assumptions, and limitations

1. reward‑gated Hebb 不减 baseline，导致所有 rewarded coactivity 持续增强。
2. matching 当作无条件理性最优 law。
3. blocking 解释成 S2 没有和 reward 同时出现。
4. 把 RPE、value 与 salience 混为一谈。
5. TD error 中漏掉 γ 或 next value。
6. 把 dopamine 视为所有 reward learning 的唯一第三因子。
7. 提前把本课简化 Q 概念当作完整 Q‑learning algorithm。

  Course‑specific risk boundary. Lecture 24 是 biological/reward‑learning bridge，Lecture 25
  才系统化 MDP/RL。不要提前让 Bellman/Q‑learning 淹没本课的 plasticity 与 dopamine 逻辑。

2. eligibility 与 reward 的 covariance。
3. 两个 chosen options 的 expected reward rate 相等。
4. choice ratio≈reward ratio（在特定 assumptions 下）。
5. R−V。
6. 已有 cue 使 V≈R，新 cue 出现时 prediction error≈0。
7. 几乎只重视 immediate reward。
8. δ=R_{t+1}+γV_{t+1}−V_t。
9. cue 变成 earliest predictor，RPE 在 cue 时 positive，expected reward 时为零。
10. 预期 reward 应出现但未出现的时刻。
11. Q 条件化 action；V 只条件化 state/policy。
