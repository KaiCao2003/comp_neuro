5.1 integrating factor 与 causal kernel

【必要前置】      求 τ dx/dt=−x+I(t) 的任意 time‑varying input 解。

                                      d ( t/τ ) 1
                                          xe       = I(t)et/τ
                                     dt              τ
                                                     ∫ t ′
                                                         dt −(t−t′ )/τ ′
                          x(t) = x(t0 )e−(t−t0 )/τ +       e          I(t )
                                                      t0 τ
                                                  1 −t/τ
                                       Kτ (t) =     e    H(t)
                                                  τ
1. 乘以 e^{t/τ}，使左侧成为 product derivative。
2. 从 t0 积分到 t，保留 initial‑condition term。
3. 若把 t0→−∞ 且初始 transient 已消失，得到纯 convolution。
4. kernel 权重随过去时间差指数衰减，面积为 1。

  Geometric/computational intuition. 当前 state 是所有过去输入的加权平均，最近输入权重大。
  Biological interpretation / failure condition. τ 或 coefficients 随时间/状态变化时，不再是固定
  linear convolution。

5.2 exponential convolution ↔ synaptic‑current ODE

【补全推导】      把每个 spike 的 exponential current sum 改写为 state equation。
                                                             
                                          ∑          ∑
                          Ii (t) = Kτs ∗   Wij ∆j +   Uij Xj 
                                               j              j

                                               ∑              ∑
                              τs I˙i = −Ii +       Wij ∆j +       Uij Xj
                                               j              j

1. K_τ 是一阶低通系统的 impulse response。
2. 对 convolution 求导并利用 τK’+K=δ。
3. 每个 network neuron 需要 voltage state V_i 和 synaptic‑current state I_i，共 2N ODEs。
4. IF threshold/reset 作为事件规则额外耦合 spike train。

  Geometric/computational intuition. 不必保存全部 spike history；一个递归 state I_i 就压缩了
  指数加权过去。
  Biological interpretation / failure condition. double‑exponential、
                                                                   NMDA 或 short‑term plas‑
  ticity 需要更多 states。

5.3 从 spike averages 到 rate model

【跨页连接】      何时可以把随机 spikes 替换为 smooth rate h_i？
                                        ∑          ∑
                         τs I˙i = −Ii +   Wij hj +   Uij χj
                                            j            j

                                         hi = F(Ii )
                                     τr ḣi = −hi + F(Ii )
1. 在比 ISI 长、比 network changes 短的窗口平均 spike train。
2. 假设窗口内 I 与 rates 变化不大，将 expected spike count/Δt 替换为 h。
3. 最简模型假设 rate 瞬时等于 F–I curve；更一般模型赋予 rate response time τ_r。
4. 若 τ_s≪τ_r 或 τ_r≪τ_s，可消去 fast variable，得到不同 reduced forms。

  Geometric/computational intuition. rate variable 是动力学状态，不只是事后 PSTH；它近似大
  量 spikes 的局部平均。
  Biological interpretation / failure condition. 稀疏 spikes、精确 synchrony、快速 transient
  或 multimodal variability 时 averaging 失效。

5.4 feedforward layer composition

【模型边界】      W=0、steady state 时如何形成深层网络？

                                      h(1) = F(U (1) x)

                                    h(ℓ) = F(U (ℓ) h(ℓ−1) )
1. 去掉 recurrence 后每层只依赖前一层。
2. fast steady‑state approximation 将 dynamics 变成静态 nonlinear map。
3. 重复 composition 形成 deep feedforward architecture。
4. 这里仅建立表示结构，权重训练在 Lecture 11。

  Geometric/computational intuition. 每层做 linear mixing + pointwise nonlinearity，逐级构
  造新 features。
  Biological interpretation / failure condition. 真实 recurrent/sensory networks 可能没有清晰
  同步层或 steady‑state separation。

6 Cross‑page synthesis / 跨页因果与数学链

  一阶线性 ODE 的解是对过去输入的 causal exponential convolution；反过来，exponential con‑
  volution 可 用 一 个 额 外 state variable 的 ODE 实 现。 这 一 等 价 让 spiking network 变 成 volt‑
  age+current 的 coupled system，并在时间平均与 time‑scale separation 下导出 rate models。
  不同 rate‑model forms 对哪些变量被视为 fast/slow 有不同假设，不能只凭外观互换。

7 Worked examples and transfer

7.1 exponential kernel normalization

【原课/核心例题】         Prompt. K(t)=e^{‑t/τ}/τ, t≥0。

 Worked solution. ∫_0^∞K(t)dt=1；因此常输入 I0 的稳态输出仍是 I0。
 Check. 若遗漏 1/τ，kernel area 会是 τ，改变 gain 和单位。


7.2 选择 rate approximation

【跨课连接】       Prompt. synapse 很慢、rate relaxation 很快。

 Worked solution. 设 τ_r dh/dt≈0，得到 h≈F(I)，保留 τ_s dI/dt；即 fast‑rate/slow‑synapse form。
 Check. 近似必须明确被忽略的是哪一个 derivative，而不是只说“快”。

10 Common traps, assumptions, and limitations

1. 遗漏 exponential kernel 的 1/τ normalization。
2. 把 membrane τ、synaptic τ_s、rate τ_r 混为一个时间常数。
3. 把统计 firing‑rate estimate 自动等同于 dynamical rate variable。
4. 做 fast‑variable approximation 却不写被设为零的 derivative。

6. 把 feedforward architecture 与 backprop training 混为一谈。
