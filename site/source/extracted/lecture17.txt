5.1 Hubel–Wiesel pooling 与 simple‑cell selectivity

【必要前置】      如何由 center‑surround subunits 形成 oriented RF？
                                X       RGC/LGN
                            L=     w j rj       , h = [L]+
                                      j

1. 将空间上排成一列的 ON/OFF subunits 赋予合适正负 weights。
2. aligned edge 同时激活多个同号 subunits，linear sum 大。
3. orthogonal/错位 edge 正负贡献抵消。
4. rectification 产生 firing‑rate selectivity。

  Geometric/computational intuition. orientation selectivity 可由多个较小 RF 的几何排列涌现。
  Biological interpretation / failure condition. 真实 V1 selectivity 还受 recurrence、conduc‑
  tance 与 adaptation 调节。

5.2 quadrature energy model 与 phase invariance

【补全推导】      为什么两个相差 90° 的 filters square‑and‑sum 后不依 phase？

                                  L1 = A cos ϕ,         L2 = A sin ϕ

                            E = L21 + L22 = A2 (cos2 ϕ + sin2 ϕ) = A2
1. quadrature pair 具有相同 orientation/frequency，phase 差 π/2。
2. 同一 grating phase 在两个 filters 上投影成 cos 与 sin components。
3. 平方消除符号，求和利用 trigonometric identity。
4. 输出保留 orientation/frequency energy，却消除 phase dependence。

  Geometric/computational intuition. complex cell 检测某 orientation 的局部能量，而非精确亮
  暗 lobe alignment。
  Biological interpretation / failure condition. 有限 filter set、nonideal quadrature 或 normal‑
  ization 会留下 phase modulation。

  Micro‑check

5.4 E/I nullclines 与 surround suppression

【模型边界】      surround input 如何让 E、I rates 同时下降？

                           τE ṙE = −rE + FE (WEE rE − WEI rI + IE )

                            τI ṙI = −rI + FI (WIE rE − WII rI + II )
1. steady state 是两条 nullclines 的 intersection。
2. surround 可增加 inhibitory‑population drive，使 I‑nullcline 移位。
3. 新 intersection 可有更低 r_E 和更低 r_I；excitation decrease 更大使 pyramidal firing suppressed。
4. 若 E subnetwork 单独不稳定但由 feedback inhibition 稳定，称 inhibition‑stabilized network。

  Geometric/computational intuition. “inhibition stabilizes”不等于 steady‑state inhibitory
  rate 必须上升。
  Biological interpretation / failure condition. nullcline conclusion 依 nonlinear gain‑
  s/weights；不同 circuits 可给相同 phenomenology。

  Micro‑check
  surround suppression 是否要求 inhibition 增加？

 6 Cross‑page synthesis / 跨页因果与数学链

   feedforward cascades 可逐级构造 selectivity 与 invariance，但 descriptive blocks 不自动指定
   biological mechanism。complex cells 对 grating phase 近 invariant，因而单一 linear STA 可为
   零；quadrature‑pair square‑and‑sum 的 energy model 给出最小解释。surround suppression 也
   不能简单等于“更多 inhibition”：recurrent E/I network 可使 excitation 和 inhibition 同时下降，
   只是 excitation 降得更多；nullcline geometry 揭示 inhibition‑stabilized regime。

10 Common traps, assumptions, and limitations

1. 把 descriptive LNP cascade 自动当作 anatomy/mechanism。
2. complex‑cell STA=0 就说无 stimulus selectivity。
3. 忘记 square 后 sign/phase 信息被改变。
4. 把 task accuracy 与 neural predictivity 当同一指标。
5. surround suppression 等同于 inhibitory firing/conductance 必然增加。
6. 把 ISN 名称理解为 inhibition rate 总是更高。
7. 只看 fixed point 不检查 stability。

  Course‑specific risk boundary. 明确“复杂细胞 STA=0”不等于“没有 stimulus selectivity”
                                                                          ；这
  是理解 nonlinear system identification 的关键反例。
