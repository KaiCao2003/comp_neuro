5 补全推导与数学支架 / Derivations

5.1 从 Boltzmann ratio 到 Nernst equation

【必要前置】      求单一离子跨膜达到净通量为零时的电位差。
                               Pin
                                    = e−(Uin −Uout )/(kB T )
                               Pout
                              U = qϕ,     Vm = ϕin − ϕout
                                         kB T    [c]out
                                  Ec =        ln
                                          qc      [c]in
1. 平衡时占据概率比同时反映浓度比与电势能差。
2. 把 U=qφ 代入，并采用 V_m=φ_in−φ_out 的符号 convention。
3. 取自然对数并解出 V_m。
4. 离子 valence 进入 q_c=z e，因此 Ca²+ 的电压尺度有 1/2 因子。

  Geometric/computational intuition. E_c 是电场恰好抵消扩散驱动力的电压，不等于膜在任意时
  刻的实际 V_m。
  Biological interpretation / failure condition. 多离子同时通透、浓度随时间改变或主动泵显著时，
  单离子 Nernst equation 不足。

5.2 电容与电流积分

【补全推导】      只有 capacitor 时，外加电流如何改变 V_m？

                                           Q = CVm
                                           dQ      dVm
                                      IC =      =C
                                            dt      dt
                                                   ∫ t
                                                 1

1. 膜两侧导电溶液被 lipid insulator 分开，能储存相反电荷。
2. 电流是电荷变化率；若 C 固定，I=C dV/dt。
3. 恒定电流产生 linear voltage ramp，斜率 I/C。
4. 加入 threshold 与 reset 即得到 pure integrate‑and‑fire。

  Geometric/computational intuition. 更大的 C 需要更多电荷才能改变同样电压，所以电位变化更
  慢。
  Biological interpretation / failure condition. 真实膜有 leak 和 voltage‑gated currents，不能
  长期线性积累。

5.3 leak current 与 LIF 方程

【跨页连接】      加入被动通道和 reversal battery 后如何写 current balance？

                                     IL = GL (Vm − EL )

                                   dVm
                               C       = Ie − GL (Vm − EL )
                                    dt
                                               C
                                         τm =
                                               GL
1. resistor 支路的电压降是 V_m−E_L；Ohm’s law 给出 outward leak current。
2. Kirchhoff current law：进入 capacitor 的净电流等于 external current 减去 leak。
3. 无外加电流时 V_m 被拉回 E_L。
4. threshold/reset 是对 subthreshold differential equation 的额外事件规则。

  Geometric/computational intuition. leak 让 模 型 从 无 限 记 忆 的 integrator 变 成 指 数 遗 忘 的
  leaky integrator。
  Biological interpretation / failure condition. G_L 若依赖电压或存在多个动态 conductances，
  需要 HH 类模型。

6 Cross‑page synthesis / 跨页因果与数学链

  神经膜同时是电荷分离的 capacitor 和离子选择性通道的 conductance network。扩散推动离子沿浓
  度梯度移动，电场推动带电粒子沿电势能下降方向移动；二者平衡定义每种离子的 reversal potential。
  电路等效并非比喻装饰，而是把 charge conservation、Ohm’s law 与 channel selectivity 组合成
  可求解的膜电位方程。

7 Worked examples and transfer

7.1 Nernst sign check

【原课/核心例题】         Prompt. K+ 通常细胞内浓度高于外部。

 Worked solution. [K]out/[K]in<1，log ratio 为负；q_K>0，所以 E_K<0，符合约 −75 mV。Cl− 的
 q<0，会反转符号。
 Check. 只看浓度比而不看 ion charge 会把阴离子符号算错。


7.2 pure IF firing rate

【跨课连接】       Prompt. 恒定 I_e 从 reset V_R 充到 threshold V_T。

 Worked solution. ΔV=V_T−V_R，充电时间 Δt=CΔV/I_e，因此 rate r=1/Δt=I_e/[C(V_T−V_R)]。
 Check. 单位 A/[F·V]=1/s；若 I_e≤0 不会向上越阈值。

10 Common traps, assumptions, and limitations

1. 把 equilibrium potential 当作细胞实际瞬时膜电位。
2. 忘记 V_m=inside−outside 的符号 convention。
3. 对 Cl− 使用阳离子符号直觉。
4. 把 current direction、positive charge movement 和 voltage change 混为一谈。
5. 认为 capacitor 支路有离子跨膜；理想 capacitor 表示膜两侧电荷重新分布。
6. 把 threshold/reset 当作 LIF differential equation 自然产生的 action potential。

  Course‑specific risk boundary. 本课只铺到 LIF equation；不要提前吞并 Lecture 5 的完整 LIF
  closed‑form solution 与 HH gating dynamics，但可在结尾给出明确预告。
