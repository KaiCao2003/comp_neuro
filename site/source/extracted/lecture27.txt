5.1 empirical observations 与 standard consolidation

【必要前置】      recent/remote amnesia 与 memory quality 如何组织理论？

    recent: hippocampus‑dependent, detailed    −→    remote: distributed cortical, gist‑like

1. patient evidence（如 E.P.）显示 bilateral hippocampal damage 严重影响 new explicit memories，
   并常有 temporal gradient。
2. place‑cell replay 在 rest/sleep 中以 compressed sequences 重现 trajectories。
3. standard account 认为 replay/reactivation 驱动 neocortical plasticity。
4. single cases 与 correlations 不能单独证明唯一 mechanism。

  Geometric/computational intuition. 记忆不是简单从一个硬盘复制到另一个；representation
  与 detail 也会改变。
  Biological interpretation / failure condition. multiple trace/transformation views 与 task‑
  dependent hippocampal roles 提供替代理论。

5.2 Teacher–Student–Notebook formal roles

【补全推导】      三个系统分别解决什么 computational problem？

                                       z ∼ P (z | θT )

3. Notebook/hippocampus 用 autoassociative one‑shot storage 保存 episodes。
4. notebook pattern separation 减少 memories interference，pattern completion 支持 replay/seed‑

1. memory/training error 只在 notebook stored examples 上评估。
2. generalization error 对 teacher distribution 的新 samples 取 expectation。
3. fast notebook 可令 stored pattern recall 很好，即 e_m 低。
4. student 需要多 examples 才能估 teacher signal，过度拟合 ε 会使 e_g 上升。

5.4 Go‑CLS stopping 与 predictability

【模型边界】      何时应停止 hippocampus→cortex consolidation？

                                  E[(wTT x)2 ]
                           λs =                  (predictability/SNR)
                                    E[ϵ2 ]

                                        t∗ = arg min eg (t)

1. 早期 transfer 学 signal，e_g 下降。
2. 继续 replay 后，student 开始拟合 notebook 中的 unpredictable ε，e_g 回升。
3. Go‑CLS 在 minimum generalization error 附近停止/衰减 transfer。
4. 高 λ_s memories 更可 corticalize；低 λ_s detail 保持 hippocampal dependence。

  Geometric/computational intuition. 最优 consolidation 不是复制到零 training error，而是最
  大化未来 prediction。
  Biological interpretation / failure condition. brain 如何估计 predictability/停止时机是 model
  prediction，需实验检验。

 6 Cross‑page synthesis / 跨页因果与数学链

   systems consolidation 同时改变 memory 的 anatomical dependence 与 psychological charac‑
   ter：recent memories 更 vivid/episodic，remote memories 更 gist‑like/semantic。Teacher–
   Student–Notebook framework 把 environment/teacher 看作 generative source，neocortical
   student 慢学 predictive structure，hippocampal notebook 快速存 one‑shot episodes 并 replay。
   标准持续 transfer 会把 unpredictable noise 也写入 student，降低 generalization；Go‑CLS 根据
   signal predictability/SNR 控制 transfer 并在最优点停止，因此 unpredictable episodic detail 保
   持 hippocampus‑dependent。

10 Common traps, assumptions, and limitations

1. 把 patient E.P. 单一案例当作全部 consolidation 机制证明。
2. recent=hippocampus、remote=neocortex 写成绝对二分。
3. replay correlation 直接等于 causal synaptic transfer。
4. 把 Teacher/Student/Notebook 当作一一解剖标签而非 formal roles。
5. memory error 与 generalization error 混为同一指标。
6. training error 越低就认为 consolidation 越好。
7. 把 Go‑CLS predictions 写成已证实事实。

  Course‑specific risk boundary. 明确区分 empirical observations、standard theory、Teacher–
  Student–Notebook formal model 和 Go‑CLS predictions；不要把模型预测写成已证实事实。
