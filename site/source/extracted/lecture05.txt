【必要前置】      恒流 I_e 下 V_m 如何接近稳态，何时能放电？

                                     C V̇ = Ie − GL (V − EL )

                                                      C               Ie
                          τm V̇ = −V + V∞ ,   τm =       , V ∞ = EL +
                                                      GL              GL
                                 V (t) = V∞ + (VR − V∞ )e−t/τm
1. 把 leak 方程除以 G_L，识别 time constant 与 steady state。
2. 解与 Lecture 3 的一阶系统同形。
3. 只有 V_∞>V_T 才可能越 threshold。

                   C V̇ = Ie − ḠL (V − EL ) − ḠN a m3 h(V − EN a ) − ḠK n4 (V − EK )

                                                                 n∞ (V ) − n

                                                                   τn (V )
                                             αn                  1

1. m 表示 Na activation，
                     h 表示 Na inactivation，
                                         n 表示 K activation；
                                                          它们是 gate‑open probability‑like
   variables，不是 channel count。
2. depolarization 快速提高 m，产生 inward Na positive feedback。

  真实 neurons 有更多 channel types 与 morphology。

7.1 LIF 数值 threshold

【原课/核心例题】         Prompt. E_L=−65 mV, V_T=−50 mV, G_L=10 nS。

 Worked solution. I_T=G_L(V_T−E_L)=10 nS×15 mV=150 pA。只有 I>150 pA 时恒流 steady state
 超过 threshold。
 Check. nS·mV=pA；若 V_R 更低，它改变 ISI 但不改变 I_T。

10 Common traps, assumptions, and limitations

1. 混淆 τ_m、ISI 与 refractory δ。
2. 认为 V∞=V_T 时会在有限时间越阈值；实际上只渐近接近。
3. 把 threshold‑linear F–I 当成 exact LIF。
4. 把 m、h、n 当作离子通道个数。
5. 忘记 current=conductance×driving force；gate 增加不保证 current 方向。
6. 把 HH 当作所有 neurons 的唯一模型。

  Course‑specific risk boundary. 明确区分 membrane time constant、interspike interval 和
  refractory period；明确区分 channel activation probability、conductance 与 ionic current。
