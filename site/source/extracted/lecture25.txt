5 补全推导与数学支架 / Derivations

5.1 MDP 与 Markov property

【必要前置】      定义 squirrel foraging 的 formal components。

                           P (st+1 , Rt+1 | s0:t , a0:t ) = P (st+1 , Rt+1 | st , at )

                                                at ∼ π(a | st )
1. agent 选择 action，environment 根据 transition distribution 产生 next state/reward。
2. state 必须包含预测 future 所需信息，如位置、可见威胁、资源状态等。
3. 若 state 缺记忆变量，observations 可能非‑Markov。
4. policy 是 state 到 action distribution，不等于 transition model。

  Geometric/computational intuition. Markov 性是 representation 的充分性条件，而非世界真
  的无历史。
  Biological interpretation / failure condition. partial observability 时需 belief state/recur‑
  rent memory。

5.2 return、V 与 Q

【补全推导】      量化 long‑term reward。

                              Gt = Rt+1 + γRt+2 + γ 2 Rt+3 + · · ·

                                    Vπ (s) = Eπ [Gt | st = s]
                              Qπ (s, a) = Eπ [Gt | st = s, at = a]
1. 0≤γ<1 使远期 reward 权重几何衰减并帮助 continuing tasks 收敛。
2. V 在 policy π 下从 state 出发平均；Q 额外固定第一 action。
3. V_π(s)=E_{a∼π}Q_π(s,a)。
4. optimal policy 选择最大 Q* 的 action（ties 可多解）。

  Geometric/computational intuition. Q 把“现在做什么”与未来 consequences 连接。
  Biological interpretation / failure condition. episodic finite horizon 可允许 γ=1；reward
  scaling 与 termination 需明确。

5.3 Bellman optimality equation

【跨页连接】      递归表示 Q*。

                       Q∗ (s, a) = E[Rt+1 + γ max
                                               ′
                                                  Q∗ (st+1 , a′ ) | st = s, at = a]
                                                       a
                                   X
                               =           p(s′ , r | s, a)[r + γ max
                                                                   ′
                                                                      Q∗ (s′ , a′ )]
                                                                   a
                                   s′ ,r

1. 将 G_t 拆成 R_{t+1}+γG_{t+1}。
2. 第一步 action a 固定；下一 state 后采用 optimal future action。
3. 对 environment stochastic transition/reward 取 expectation。
4. equation 是 self‑consistency relation；已知 model 时可用 dynamic programming 求解。

  Geometric/computational intuition. 一个 state‑action 的价值等于一步 reward 加最优 future
  的折扣价值。
  Biological interpretation / failure condition. 把 max 放到 expectation 外/内位置写错会改变
  stochastic problem。

5.4 Q‑learning 与 exploration

【模型边界】      未知 transition model 时如何从 experience 学 Q*？

                                δt = Rt+1 + γ max
                                               ′
                                                  Q(st+1 , a′ ) − Q(st , at )
                                                 a

                                        Q(st , at ) ← Q(st , at ) + αδt
1. sample transition 给 Bellman target 的 noisy sample。
2. update 只改 visited state‑action entry。
3. target 使用 greedy max，而 behavior 可以 ε‑greedy，因此 off‑policy。
4. tabular convergence 需充分 exploration、适当 decaying learning rates 与 stationary finite MDP
   等条件。

  Geometric/computational intuition. 把当前 Q 向 one‑step bootstrap target 移动。
  Biological interpretation / failure condition. function approximation、off‑policy 与 boot‑
  strap 可共同引发 instability；state coverage 不足也失败。

5.5 model‑based RL、planning 与 replay

【必要前置】      generative model 如何提高 sample efficiency？

                                                pb(s′ , r | s, a)

                           real or simulated (s, a, r, s′ ) → planning/update
1. agent 学 transition/reward model。
2. 可在不实际行动时模拟 trajectories、评估 detours/changed reward。
3. hippocampal state/place representations 与 replay 提供候选 biological substrate。
4. replay 与 exact Bellman backup 是层级推断，不能直接等同。

  Geometric/computational intuition. world model 把过去 experience 重组为未实际经历的
  counterfactual updates。
  Biological interpretation / failure condition. model bias 会在 planning 中累积；computa‑
  tional cost 也更高。

6 Cross‑page synthesis / 跨页因果与数学链

  MDP 的核心不是“环境没有历史”，而是 chosen state representation 使 future 在给定 current
  state/action 后与更早历史条件独立。discounted return 可递归拆成 immediate reward + γ future
  return，导出 Bellman optimality equation。Q‑learning 用 sampled Bellman error 做 off‑policy
  bootstrap update；model‑based RL 另学习 transition/reward model，并可通过 simulated ex‑
  perience/replay 提高 sample efficiency。

10 Common traps, assumptions, and limitations

1. Markov property 等于环境没有历史。
2. 混淆 Vπ、Qπ、V*、Q*。
3. Bellman equation 忘记 transition expectation。
4. Q‑learning target 使用 behavior action 而误写成 SARSA。
5. ε‑greedy 的 random branch 只在非 greedy actions 中选而不说明 convention。
6. 把 model‑free 等同于无 internal representation。
7. 把 hippocampal replay 直接等同于精确 Bellman backup。

  Course‑specific risk boundary. 不要把 Q‑learning 与所有 TD learning 同义化；不要把 hip‑
  pocampal replay 直接等同于精确 Bellman backup，必须标明 evidence 与 inference 的层级。

 1. state representation 的 conditional sufficiency。
 2. policy 由 agent 选 action；transition model 由 environment 给 next state/reward。
 3. myopic，主要重视 immediate reward。
 4. Q additionally conditions on first action。
 5. 选择 argmax_a Q*(s,a)。
 6. next state 的 future actions 上，位于 transition expectation 内部的 bracket 中。
 7. R+γmax_{a’}Q(s’,a’)−Q(s,a)。
 8. target 使用 greedy max，而 behavior 可 exploratory。
 9. 控制新 Bellman target 对现有 estimate 的更新幅度。
10. 持续随机 actions 降低 immediate reward，且 uniform exploration 低效。
11. 更 sample‑efficient/flexible planning；model bias 与 computation cost。
12. animals 可能学习 generative/cognitive map，而非只缓存固定 action values。
