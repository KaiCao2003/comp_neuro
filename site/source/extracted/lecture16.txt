5.1 SNR 与 optimal spatial profile

【必要前置】      为何 light level 改变 center‑surround strength？

                                                 S(ξ)
                                     SN R(ξ) =
                                                 N (ξ)

1. 高 SNR 时 signal structure 可信，strong surround 可减去 correlated low‑frequency redundancy。
2. 低 SNR 时高频变化多为 noise，spatial averaging 提高 reliability。
3. intermediate SNR 在 whitening 与 low‑pass 之间连续折中。
4. information constraint 防止简单把所有 gain 压到零。

  Geometric/computational intuition. filter 应放大可预测的 signal differences，而不是噪声。
  Biological interpretation / failure condition. 单 一 scalar SNR 可 能 过 度 简 化 frequency‑
  dependent、adaptation‑state‑dependent noise。

5.2 translation invariance 与 Fourier transform

【补全推导】      为什么 spatial frequency 是 natural‑scene statistics 的便利坐标？

                                    Cs (ρ1 , ρ2 ) = Cs (ρ1 − ρ2 )
                                             ∫
                                   ŝ(ξ) = dd x e−i2πξ·x s(x)
                                            ∫
                                   s(x) =       dd ξ ei2πξ·x ŝ(ξ)

1. translation invariance 说 covariance 只看两点 separation，不看 absolute location。
2. complex exponential 同时编码 sine/cosine amplitude 与 phase。
3. vector ξ 的方向给 grating normal，大小给 cycles per distance。
4. Fourier modes 是 shift‑invariant linear operators 的 eigenfunctions。

  Geometric/computational intuition. 一张图可分解为不同方向、尺度和 phase 的 sinusoidal
  components。
  Biological interpretation / failure condition. 有限 image、
                                                         edges、
                                                              nonstationarity 与 sampling
  会引入 windowing/aliasing。

5.3 convolution theorem

【跨页连接】      证明 spatial filtering 在 frequency domain 变成乘法。
                                             ∫
                                 (f ∗ g)(x) = f (x′ )g(x − x′ )dx′


                                        f[
                                         ∗ g(ξ) = fˆ(ξ)ĝ(ξ)
1. 把 convolution definition 代入 Fourier integral。
2. 交换积分顺序。
3. 令 u=x−x’，exponential phase 分解为 e^{‑iξx’}e^{‑iξu}。
4. 两个独立积分分别成为 fhat 与 ghat。

  Geometric/computational intuition. 每个 spatial frequency 是 filter 的独立 gain channel。
  Biological interpretation / failure condition. 非线性、space‑varying filters 或 boundary han‑
  dling 不能仅用 pointwise multiplication 表示。

5.4 natural power spectrum 与 whitening trend

【模型边界】      若 C_hat(ξ)∝1/|ξ|²，什么 filter 使 output power flat？

                                      Pout (ξ) = |K̂(ξ)|2 Pin (ξ)

                                   Pin (ξ) ∝ |ξ|−2 ⇒ |K̂(ξ)| ∝ |ξ|
1. whitening 要求 P_out 近 constant。
2. 因此 filter magnitude 是 input power 的 inverse square root。
3. natural low frequencies power 高，所以 whitening 相对 boost high frequencies。
4. optical/photoreceptor low‑pass 与 noise 在 very high frequencies 降低 optimal gain。

  Geometric/computational intuition. center‑surround 类似 spatial derivative/high‑pass，但
  生物系统不会无限放大最高频噪声。
  Biological interpretation / failure condition. 1/|ξ|² 是 approximate average law；特定 scenes、
  orientation statistics 与 contrast distributions 更复杂。

6 Cross‑page synthesis / 跨页因果与数学链

  Atick–Redlich theory 的关键预测不是固定 filter，
                                       而是 filter 随 SNR 改变：高 SNR 可强 decorrelate，
  低 SNR 更应 spatial average/denoise。自然场景近似 translation invariant，使 covariance 只
  依 displacement，Fourier modes 因而对角化 convolution/covariance。natural‑image power
  近似随 spatial frequency 平方反比下降；perfect whitening 倾向 boost high frequencies，但
  optics/photoreceptors 与 noise 会抑制过高频率。

10 Common traps, assumptions, and limitations

1. 把 Fourier transform 当作无物理意义的公式表。
2. 混淆 spatial frequency magnitude、orientation 与 phase。
3. 认为 complex numbers 引入额外生物变量；它只是表示工具。
4. convolution theorem 忽略 normalization/sign convention。
5. 把 1/|ξ|² 当作每张图像的精确 law。
6. perfect whitening 无限 boost high frequencies，忽略 optics/noise。
7. 适应实验只比较 firing rate，不比较 filter/nonlinearity。

  Course‑specific risk boundary. 不要把 Fourier transform 教成纯公式表。必须始终回答 spatial
  frequency 对图像和 receptive field 的物理含义，以及 amplitude/phase 分别表示什么。
