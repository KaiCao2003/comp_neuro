6.1 PCA low‑dimensional variance 与限制

【必要前置】      为什么 many neurons 可由 few components 描述？

                                     rt ≈ r̄ + VK at
                                              X        X
                               VarFrac(K) =       λk /   λj
                                             k≤K      j

1. centered population activity 的 covariance eigenvalues 常快速衰减。
2. V_K columns 是 high‑dimensional embedding axes，a_t 是 low‑dimensional coordinates。
3. 低维表示可压缩 shared dynamics，但 discarded dimensions 仍可能含 output/condition informa‑
   tion。
4. tuning curve 是单 neuron stimulus average，与 trajectory coordinates 不同。

  Geometric/computational intuition. 许多 neurons 可共同参与少数 coordinated population
  patterns。
  Biological interpretation / failure condition. PCA 不建模 temporal smoothness，也无法区分
  shared dynamics 与 observation noise。

6.2 GPFA observation 与 temporal prior

【补全推导】      如何同时建模 latent factors、neuron loadings 与 smooth time course？

                                    rt | αt ∼ N (Cαt + d, Σ)

                                       αk (1:T ) ∼ N (0, Kk )
                                          2                     ′ 2
                                                      2 −(t−t ) /(2τk )
                                                                      2
                              [Kk ]tt′ = σn,k δtt′ + σs,k e
1. r_t∈R^N，α_t∈R^K，C∈R^{N×K}，d∈R^N，Σ∈R^{N×N}。
2. observation model 把 latent state linear embed 到 neuron space。
3. Gaussian‑process covariance 让 nearby time points correlated/smooth。
4. C 与 α 有 scale/rotation non‑identifiability，需 convention/constraints。

  Geometric/computational intuition. GPFA 把 observed spikes/rates 看作 smooth shared tra‑
  jectory 加 neuron‑specific noise。
  Biological interpretation / failure condition. Gaussian observations、stationary kernels 与
  fixed dimensionality 可能不适合 abrupt/nonlinear dynamics。

6.3 output‑null preparatory activity

【跨页连接】      为什么 preparation 可变化而 muscles 不动？

                                          m = Ur

                                    U ∈ RM ×N , M < N
                                rnull ∈ Null(U ) ⇒ U rnull = 0
1. U 是 neural‑to‑muscle/output linear readout。
2. rank(U)≤M，因此 null‑space dimension 至少 N−M。
3. 不同 target 可在 null directions 建立不同 preparatory states。
4. go cue 后 dynamics 转入 output‑potent/movement modes。

  Geometric/computational intuition. 大 population 可在不影响当前 output 的自由度中预先设
  置 initial condition。
  Biological interpretation / failure condition. 真实 readout nonlinear/time‑varying；null‑
  space 是 local linear approximation。

6.4 BMI closed loop 与 latent alignment

【模型边界】      为什么同一 neuron decoder 跨日漂移，而 latent decoder 更稳定？

                                   bt = Brt
                                   v             b t = Bα αt
                                              or v

1. feedforward BMI 只把 recorded activity 映射为 command。
2. closed loop 加 device/sensory feedback，用户可在线纠错与学习。
3. individual neuron tuning/loading 可漂移，而 shared latent manifold/dynamics 可能较稳定。
4. 对齐每日 latent spaces 后再 decode，可减少 neuron‑identity drift。

  Geometric/computational intuition. 稳定的计算可能存在于 population geometry，而非固定
  单 neuron coordinates。
  Biological interpretation / failure condition. latent stability 不是保证；task、electrode、learn‑
  ing 与 pathology 均可改变 manifold。

7 Cross‑page synthesis / 跨页因果与数学链

  direction tuning 是 motor cortex 的经典描述，但现代 population view 关注 low‑dimensional
  trajectories 是否生成 movement dynamics。GPFA 用 Gaussian observation model 把 smooth
  latent factors 嵌入 noisy neural activity，显式建模 time covariance。preparatory state 可沿
  muscle readout U 的 null space 变化而不产生 movement；BMI 则把 neural/latent state 解码为
  device commands，并利用 feedback 与跨日 latent alignment 提高稳定性。

11 Common traps, assumptions, and limitations

1. 把 single‑neuron tuning curve 与 latent trajectory 混为一谈。
2. PCA components、GPFA factors、dynamical modes 与 decoder axes 互换使用。
3. K low‑dimensional 就认为只有 K neurons 重要。
4. 忽略 C–α scale/rotation non‑identifiability。
5. Ur=0 就认为 r=0。
6. feedforward BMI 忽略 user feedback/learning。
7. 把 latent cross‑day stability 写成绝对不变。

  Course‑specific risk boundary. 明确区分 tuning curve、principal components、latent factors、
  dynamical modes 和 decoder axes；这些概念可相关但不可互换。
