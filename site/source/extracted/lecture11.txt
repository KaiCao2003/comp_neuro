5 补全推导与数学支架 / Derivations

5.1 Taylor expansion 到 gradient descent

【必要前置】      如何选择小参数更新使 loss 下降？

                                L(w + ∆w) ≈ L(w) + ∇LT ∆w

                                        ∆w = −η∇L
1. gradient 指向 loss 增长最快方向。
2. 一阶近似中选择反梯度使内积为 −η||∇L||²≤0。
3. η 太小收敛慢，太大可越过 valley 或发散。
4. 二阶 curvature 决定不同方向允许的安全步长。

  Geometric/computational intuition. loss contour 上的 gradient 垂直于等高线，steepest de‑
  scent 反向下坡。
  Biological interpretation / failure condition. nonconvex loss 可有 saddle/local structure；一
  阶近似只对足够小 step 可靠。

5.2 linear regression gradient 与 closed form

【补全推导】      对 P 个 examples 拟合 y_μ≈w^Tx_μ。

                                       1 X
                                           P
                                   L=      (yµ − wT xµ )2
                                      2P
                                          µ=1

                                              1
                                   ∇w L = −     X(y − X T w)
                                              P
                                      w = (XX T )−1 Xy
                                      b
1. 定义 X=[x_1,⋯,x_P]∈R^{N×P}，y∈R^{P×1}。
2. 对每个 residual 使用 chain rule，得到 −error×input。
3. gradient 可写为 −Xy/P + XX^Tw/P：前者 Hebbian‑like，后者 stabilization。
4. 设 gradient=0 得 normal equation；若 XX^T singular 则用 pseudoinverse/regularization。

  Geometric/computational intuition. 模型把 input directions 与 target 共变部分写入 weights，
  同时抑制重复放大。
  Biological interpretation / failure condition. 共线 features、P<N、outliers 或 nonlinear target
  会使 ordinary least squares 不稳定/偏差。

5.3 deep linear network 的参数化

【跨页连接】      多层都是 linear 时为何整体仍 linear，但训练不简单？

                                b = W (L) W (L−1) · · · W (1) x = M x
                                y

1. 矩阵 composition 仍是一个 matrix M，所以 input‑output map linear。
2. 但 M 被 factorized 成多层 matrices，参数之间乘法耦合。
3. 同一个 M 可有许多 factorization，因此 optimization geometry 非凸且有 scale symmetries。
4. 这说明 function class 与 learning dynamics 是不同问题。

  Geometric/computational intuition. 深度未增加 linear function 的表达类型，却改变参数空间
  与隐式 bias。
  Biological interpretation / failure condition. 把“整体 linear”误解为 loss 对每层 weight 仍是
  convex。

  deep linear network 的 input‑output map 为什么仍 linear？



5.4 backpropagation 的 local chain rule

【模型边界】      计算每层 weight 的 gradient。

                                z(ℓ) = ϕ(h(ℓ) ), h(ℓ) = W (ℓ) z(ℓ−1)
                                                       
                                δ (ℓ) = W (ℓ+1)T δ (ℓ+1) ⊙ ϕ′ (h(ℓ) )

                                        ∂L
                                          (ℓ)
                                              = δ (ℓ) z(ℓ−1)T
                                       ∂W
1. 先 forward 保存每层 pre‑activation h 与 activation z。
2. output layer 由 loss derivative 得 δ^(L)。
3. error signal 经下一层 weight transpose 拉回，再乘 local derivative。
4. weight gradient 是 postsynaptic error 与 presynaptic activation 的 outer product。

  Geometric/computational intuition. backprop 是高效 reuse 的 chain rule，不是 error 在生物
  神经元中按同一机制反向流动的证据。
  Biological interpretation / failure condition. vanishing/exploding gradients、non‑
  differentiable operations 或错误 shape 会破坏训练。

  Micro‑check
  但其 training 为什么可非凸？

6 Cross‑page synthesis / 跨页因果与数学链

  机器学习问题必须同时指定 representation/architecture、       objective/loss 和 optimization/learning
  rule。线性回归提供最透明的例子：squared error 的 gradient 可分成 data‑dependent Hebbian‑like

  中，backprop 只是反复应用 chain rule，把 output error 经 weight transpose 与 local activation
  derivative 传回各层。

10 Common traps, assumptions, and limitations

1. 把 architecture、loss 与 optimizer 混成同一个概念。
2. 忘记 gradient 指向上升，更新应取负号。
3. matrix calculus 不标 shape，导致 transpose 错误。

                                                   15/22
NEUROSCI 366 ・Lecture 11                                Source‑aligned companion


4. 在 singular design matrix 上直接求 inverse。
5. 认为 deep linear network 的 optimization 也是线性/convex。
6. 把 backprop 当成已确立的生物突触机制。
7. 误把 source 页的历史性旁注当作严格技术结论。

  Course‑specific risk boundary. 不要把 backprop 描述成“误差直接传回神经元”的生物机制；清
  楚标为训练算法，并讨论与 three‑factor plasticity 的形式联系和机制差异。
