5.1 contrast 与 spatial convolution

【必要前置】      为何 early vision 通常建模 contrast 而非 raw luminance？

                                                          I(x, y, t) − I0
                                           s(x, y, t) =
                                                                I0
                                           ∫∫
                           L(x0 , y0 ) =        s(x′ , y ′ )K(x0 − x′ , y0 − y ′ )dx′ dy ′

1. contrast 将局部强度相对平均 luminance 归一化。
2. kernel K 平移到 receptive‑field center，与每个 pixel 相乘后积分。
3. 正/负 kernel lobes 分别使亮/暗 contrast 增加或减少 linear drive。
4. translation‑shared kernel 产生 feature map。

  Geometric/computational intuition. convolution 是在每个位置问“当前 patch 与这个 feature
  模板有多匹配”。
  Biological interpretation / failure condition. 适应、
                                                   gain control、
                                                               eye movements 或 nonlinear
  subunits 会使单一 linear filter 不足。

5.2 Difference of Gaussians center‑surround

【补全推导】      重构 ON/OFF retinal receptive fields。

         A −r2 /(2σc2 )    B −r2 /(2σs2 )
 K(r) =    2
             e          −    2
                               e          ,                               σs > σc
        2πσc              2πσs
1. 窄 Gaussian 表示 center，宽 Gaussian 表示 surround。
2. ON‑center 取中心正、surround 负；OFF‑center 反号。
3. 若积分接近零，uniform luminance 被抑制，local contrast 被强调。
4. rectification [L]_+ 只保留偏好 polarity 的 drive。

  Geometric/computational intuition. 中 心 与 周 围 比 较 可 减 少 common luminance redun‑
  dancy、突出边界。
  Biological interpretation / failure condition. 真实 RGC 有 temporal dynamics、nonlinear
  subunits 与 adaptation；DoG 是一阶摘要。

5.3 Gabor kernel、rotation 与 orientation tuning

【跨页连接】      用 localized sinusoidal filter 表示 V1 simple‑cell RF。
                                                        ′2    ′2
                                         ′   ′       −x 2−y 2
                                    K(x , y ) = Ae    2σx    2σy
                                                                   cos(kx′ + ϕ)

                               x′ = x cos θ + y sin θ,       y ′ = y cos θ − x sin θ
1. Gaussian envelope 限制 receptive‑field location/size。
2. cosine carrier 创建 alternating ON/OFF lobes，k 决定 spatial frequency，φ 决定 phase。
3. 坐标 rotation 改变 preferred orientation，而不是旋转 stimulus array 的定义。
4. nonlinearity rectifies/saturates linear drive。

  Geometric/computational intuition. Gabor 同时选择位置、方向、spatial frequency 与 phase。
  Biological interpretation / failure condition. complex cells 对 phase 更 invariant，
                                                                                  单一 linear
  Gabor 的 STA 可接近零。

5.4 spatiotemporal RF 与 motion as spacetime orientation

【模型边界】      为什么 direction selectivity 需要 space‑time tilted kernel？
                            ∫∫∫
                     L(t) =      K(x′ , y ′ , τ )s(x − x′ , y − y ′ , t − τ )dx′ dy ′ dτ

                                  K(x, y, t) = Ks (x, y)Kt (t)       (separable)
1. separable kernel 的 spatial preference 不随 time lag 改变，通常不能单独区分相反 motion direc‑
   tions。
2. moving edge 在 x–t diagram 中形成斜线，斜率对应 velocity。
3. nonseparable tilted RF 与某一斜率匹配，产生 direction selectivity。
4. rightward 与 leftward motion 对应相反 spacetime orientations。

  Geometric/computational intuition. 运动不是静态位置序列之外的新维度；它是空间与时间联合
  图案的方向。
  Biological interpretation / failure condition. 复 杂 motion、eye movement 与 nonlinear
  motion‑energy mechanisms 需多 filters/recurrence。

  视觉层级不是简单的解剖列表，而是 receptive‑field size、feature complexity、history dependence
  与 invariance 逐级变化的计算组织。LNP 将 stimulus 先投影到 linear receptive field，再经 non‑

  kernels 分别概括 center‑surround、orientation 和 motion selectivity。

10 Common traps, assumptions, and limitations

1. 把 receptive field 仅理解为视野中的几何区域。
2. 把 raw luminance 与 contrast 混用。
3. convolution kernel sign/flip convention 不说明。
4. 认为 feature map 是原图的复制，而非 filter response。
5. 混淆 Gabor orientation、phase 与 spatial frequency。
6. 认为 separable spatiotemporal RF 自动 direction selective。
7. 把 anatomical hierarchy 与单一 feedforward computation 完全等同。

  Course‑specific risk boundary. 不要把 receptive field 只说成屏幕上的“位置”
                                                               ；它是刺激到响应
  关系。说明 linear RF、classical RF 与实验定义的差异。可用 sparse‑noise RF mapping 作为个性
  化 transfer。
