6 补全推导与数学支架 / Derivations

6.1 shape‑first 线性代数

【必要前置】      判断加法、内积、外积和矩阵乘法是否定义。

                             A ∈ Rm×n , x ∈ Rn×1 ⇒ Ax ∈ Rm×1

                                               ∑
                                               n
                                   (AB)ij =          Aik Bkj
                                               k=1

                                 uT v ∈ R,      uv T ∈ Rm×n
1. 加法要求 shape 完全相同；矩阵乘法要求内维相等。
2. 内积把两个同维列向量压缩成 scalar；外积保留每一对分量组合形成 matrix。
3. Hadamard product 逐元素相乘，要求同 shape；它与矩阵乘法不是同一运算。
4. 每一步先写 shape，再算数值，可提前排除大多数错误。

  Geometric/computational intuition. 矩阵乘法是“每个输出行模板”与输入向量做内积；外积则
  构造所有成对乘积。
  Biological interpretation / failure condition. MATLAB implicit expansion 可能让 shape 不
  同的对象产生输出，但该输出未必对应题目所问的抽象运算。

6.2 Bernoulli 的 mean 与 variance

【补全推导】      从 PMF 推出二元随机变量的中心与波动。

                           P (X = x) = px (1 − p)1−x ,   x ∈ {0, 1}

                                          E[X] = p
                           Var(X) = E[X 2 ] − E[X]2 = p(1 − p)
1. X 只能取 0 或 1，所以 X^2=X。
2. E[X]=(1‑p)×0+p×1=p。
3. E[X^2]=E[X]=p，因此 variance=p‑p^2。
4. p=0 或 1 时没有随机性；p=1/2 时 variance 最大。

  Geometric/computational intuition. variance 衡量 coin flip 离其平均值的平方距离；最不确定
  的硬币波动最大。
  Biological interpretation / failure condition. Bernoulli 只描述单次 binary outcome；多个相
  关 trial 不能简单当作独立 Bernoulli。

  Micro‑check
  Bernoulli(p) 的 variance 在什么 p 最大？

6.3 Exponential distribution 的 CDF、均值与尺度

【跨页连接】      描述等待时间并从 PDF 推导可观测统计量。

                                         f (x) = λe−λx 1x≥0

                                     F (x) = 1 − e−λx (x ≥ 0)
                                   1                   ln 2               1
                          E[X] =     ,   median =           ,   SD(X) =
                                   λ                    λ                 λ
1. CDF 是从负无穷积分到 x；负值区间概率为零。
2. 区间概率由 F(b)‑F(a)=e^(−λa)−e^(−λb)。
3. 均值用 integration by parts；第二矩给出 2/λ²，故 variance=1/λ²。
4. mode 在 x=0，因为 density 随 x 单调下降。

  Geometric/computational intuition. λ 是 rate；rate 越大，典型等待时间 1/λ 越短。
  Biological interpretation / failure condition. 若 hazard 随时间改变或事件有 refractory/his‑
  tory dependence，指数等待时间模型不成立。

  Micro‑check
  Exponential(λ) 的 mean 与 SD 分别是多少？

6.4 Bivariate Gaussian、conditional mean 与 Bayes

【模型边界】      把两个有相关性的连续测量写成联合分布并进行条件更新。
                            [ 2            ]
                              σ1    cσ1 σ2
                         C=
                             cσ1 σ2  σ22
                                                         σ1
                            E[X1 | X2 = x2 ] = µ1 + c       (x2 − µ2 )
                                                         σ2
                                                P (x1 | x2 )P (x2 )
                               P (x2 | x1 ) =
                                                     P (x1 )
1. c 的符号决定椭圆倾斜方向，绝对值决定拉长程度。
2. Gaussian 情形下 c=0 等价于 independence；一般分布中 uncorrelated 不保证 independent。
3. 条件均值沿相关方向移动；给定 x2<μ2 且 c>0，x1 的条件均值低于 μ1。
4. Bayes 用 product rule 重排同一 joint probability。

  Geometric/computational intuition. conditioning 相当于在联合密度椭圆上切一条 slice，再重
  新归一化。
  Biological interpretation / failure condition. 把 likelihood 当作 parameter 的概率分布、或忘
  记 evidence 的归一化作用。

  Micro‑check
  为什么连续变量 P(X=x)=0 不与 density f(x)>0 矛盾？

11 Common traps, assumptions, and limitations

1. 把 MATLAB 的 scalar expansion 误当成抽象线性代数中的 scalar+matrix。
2. 混淆 * 与.*；前者是矩阵乘法，后者是 Hadamard product。
3. 先算数字再看 shape，导致把未定义运算算成结果。
4. 把 density 值当成某个精确连续数值的概率。
5. 认为 uncorrelated 总是 independent；只有 Gaussian 等特定情形成立。
6. 把 posterior、likelihood 和 prior 的 conditioning 方向写反。

  Course‑specific risk boundary. 审计.m 中 clear all、inv 等写法：忠实解释课程代码，同时
  指出数值计算中通常更偏好线性求解而非显式求逆。将 MATLAB 的 scalar‑plus‑matrix 行为与抽象
  线性代数严格分开。
