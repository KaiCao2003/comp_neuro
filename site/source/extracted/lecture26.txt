5.1 binary asynchronous update 与 energy descent

【必要前置】      为什么 dynamics 收敛而不是任意循环？
                                               
                                       ∑
                             Si ← sgn   Wij Sj 
                                                  j

                                          1∑
                                   E=−       Wij Si Sj
                                          2
                                             ij

                                ∆E = −(Sinew − Siold )hi ≤ 0
1. 每步只随机选择一个 neuron 更新。
2. symmetric W_ij=W_ji、W_ii=0 让涉及 i 的 energy change 合并成 −ΔS_i h_i。
3. update 选择与 local field h_i 同号的新 state，因此 product 非负、ΔE≤0。
4. 有限 state space 下 eventually 到 fixed point（或平能 plateau）。

  Geometric/computational intuition. 每个 bit 局部对齐于 neighbors，同时整个 network 沿
  energy landscape 下坡。
  Biological interpretation / failure condition. synchronous update 可出现 2‑cycles；asym‑
  metric weights 不保证该 energy。

5.2 Hebbian weights 与 P=1 retrieval

【补全推导】      证明单一 pattern ξ 是 attractor。

                                                   1
                                       Wij =         ξi ξj (i ̸= j)
                                                   N
                                          ∑                 ξi ∑
                                   hi =          Wij Sj =        ξ j Sj
                                                            N
                                          j̸=i                 j̸=i

                                    Sinew = ξi sgn(ξ · S − ξi Si )
1. 若 S=ξ，local field=(N−1)ξ_i/N，update 保持 ξ_i。
2. 若 cue 与 ξ overlap 为正且 errors 不多，sum 仍与 ξ_i 同号，errors 被纠正。
3. −ξ 也成为 attractor，因为 weights 对 global sign invariant。
4. basin size 由 initial overlap 与 finite‑size effects 决定。

  Geometric/computational intuition. 每条 weight 存储两个 bits 是否同号，local field 投票恢复
  一致 pattern。
  Biological interpretation / failure condition. patterns correlated 或 biased activity 会改变
  weights 与 basins。

5.3 P>1 的 signal–crosstalk decomposition

【跨页连接】      在目标 memory μ 上计算 local field。

                                                1 ∑ ν ν
                                                    P
                                        Wij =      ξi ξj
                                                N

1. ν=μ 项给 aligned signal。
2. ν≠μ memories 的随机 products 相加成 interference。
3. 独立 random ±1 patterns 下 mean 0，variance 是项数/N²。
4. large N 可用 Gaussian approximation 估 error P(h_i ξ_i^μ<0)。

  Geometric/computational intuition. 每个 memory 都贡献一个 weak vote，目标 signal O(1)，
  其他 memories 汇成 noise O(√α)。
  Biological interpretation / failure condition. independence/Gaussian approximation 在
  correlated/sparse patterns 下改变。

5.4 capacity、spurious mixtures 与 sparse alternative

【模型边界】      为什么 capacity ∝N 且经典常数约 0.138？

                                              α = P /N

                           αc ≈ 0.138   (classic dense random Hopfield)
                                   S mix = sgn(±ξ µ1 ± ξ µ2 ± ξ µ3 )
1. 保持 finite error 需 P 与 N 同阶，因此 capacity linear in N。
2. self‑consistent statistical‑mechanics analysis 给稳定 retrieval 临界 α_c≈0.138。
3. odd mixtures 可形成 spurious attractors，不对应任何单一 memory。
4. sparse {0,1} stochastic models 加 global inhibition/temperature，可提高 information efficiency
   并改变 capacity。

  Geometric/computational intuition. 更多 memories 让 landscape 出现错误 valleys，最终
  retrieval states 被 spin‑glass‑like states 取代。
  Biological interpretation / failure condition. 0.138N 不是 brain memory capacity，也不适用
  于 modern/sparse/structured associative memories。

6 Cross‑page synthesis / 跨页因果与数学链

  Hopfield model 把 explicit memory 抽象为 attractor dynamics：partial cue 经 recurrent up‑
  dates 收敛到 stored pattern。symmetric weights 与 asynchronous single‑neuron updates 保
  证 Ising energy 不增加。P=1 时 Hebbian weights 使目标及其反号成为 fixed points；P>1 时其他
  memories 产生 crosstalk noise，loading α=P/N 增大后 retrieval errors 上升，并在经典 dense
  random model 的 α≈0.138 附近失去稳定 retrieval。

10 Common traps, assumptions, and limitations

1. synchronous 与 asynchronous dynamics 混用 energy proof。
2. 忘记 W 必须 symmetric 且 Wii=0。
3. P=1 时只说 ξ attractor，忽略 −ξ 与 spurious/global symmetry。
4. 把 overlap 与 exact bit accuracy 混为一谈。
5. crosstalk variance 不检查 N、P scaling。
6. 把 Gaussian approximation 当精确 finite‑N law。
7. 把 0.138N 当作大脑 memory capacity。

  Course‑specific risk boundary. 明确“memory capacity 0.138N”只属于经典 dense random‑
  pattern Hopfield model 的稳定‑retrieval criterion，不是大脑记忆容量结论。
