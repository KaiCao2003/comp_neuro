5 补全推导与数学支架 / Derivations

5.1 parametric working memory 与 leaky mode

【必要前置】      如何存储连续 sample frequency？

                                      τ α̇ = −(1 − λ)α + β(t)

                                         τef f = τ /(1 − λ)
1. sample input β 把 mode amplitude 推到与 stimulus magnitude 相关的值。
2. delay 中 input≈0，state 以 τ_eff 衰减。
3. λ 接近 1 时可在数秒保持 graded value。
4. 不同 neurons 可能各自 mixed selectivity，但 population mode 稳定编码。

  Geometric/computational intuition. working memory content 是 slow population coordi‑
  nate，不必等于某一 neuron 持续高 firing。
  Biological interpretation / failure condition. activity‑silent synaptic states、dynamic coding
  或 oscillatory mechanisms 也可支持 WM。

5.2 leaky drift–diffusion model

【补全推导】      把 momentary left/right evidence 累积到 choice。

                               τa ȧ = −a + [ηR (t) − ηL (t)] + γ(t)

                              a(0) = b,   choice when a(t) = ±B
1. a 是 decision variable；−a 是 leak，η_R−η_L 是 signed evidence，γ 是 noise。
2. initial bias b 移动起点，asymmetric/collapsing bounds 改变 speed–accuracy tradeoff。
3. first passage to +B/−B 决定 choice 与 decision time。
4. coherence 增大提高 drift，通常 accuracy 上升、reaction time 下降。

  Geometric/computational intuition. decision 是 noisy running total，而不是读取单一瞬间
  stimulus。
  Biological interpretation / failure condition. urgency、sticky bounds、changing evidence
  与 nondecision time 需扩展。

5.3 psychometric/chronometric 与 neural correlates

【跨页连接】      behavioral curves 如何约束 model？

                            P (right|c) ↑ with signed coherence c

                              RT (c) typically largest near c = 0
1. psychometric curve 给 choice probability vs coherence。
2. chronometric curve 给 reaction time vs coherence。
3. 同一 DDM parameters 同时预测二者，比只拟合 accuracy 更严格。
4. LIP firing ramp 与 accumulated evidence/choice/RT 相关，但仍可能是 readout、feedback 或
   correlate。

  Geometric/computational intuition. 弱 evidence 需要更长时间才随机碰到 bound，因此慢且错
  误多。
  Biological interpretation / failure condition. motor preparation、attention、confidence 与
  task timing 可混入 recorded signals。

5.4 Wong–Wang two‑attractor phase plane

【模型边界】      如何由 nonlinear recurrent competition 产生 robust discrete choices？

                            τ ṙ1 = G1 (r1 , r2 ; I1 ),   τ ṙ2 = G2 (r1 , r2 ; I2 )

1. 两条 cubic‑like nullclines 的 intersections 是 stable/unstable fixed points。
2. 无/弱 evidence 时 separatrix 附近 noise 决定进入哪个 high‑rate attractor。
3. signed evidence 移动 nullclines/basins，增加正确 attractor probability。
4. strong evidence 可消除/极度缩小错误 basin，使 choice deterministic。

  Geometric/computational intuition. integration 把 state 推离 unstable decision boundary，
  recurrent excitation 将 choice 固化。
  Biological interpretation / failure condition. reduced model 是 biophysical network 的低维
  approximation，不是唯一决策机制。

6 Cross‑page synthesis / 跨页因果与数学链

  本课把 cognition 暂定义为 brain state 不再只由 present input 决定。短时记忆可由 persistent
  population modes 保留过去 sample，而无需当场修改 synapses。知觉决策可用 noisy evidence
  accumulation 与 bounds 描述 behavior；LIP ramps 是相关 neural variables，不自动证明机制。
  Wong–Wang reduced attractor model 用 two‑dimensional nonlinear nullclines 把 integration、

10 Common traps, assumptions, and limitations

1. 把 cognition 定义当作完整哲学/心理学定义。
2. 认为 STM 必须通过当场 synaptic plasticity。
3. persistent single‑cell activity 与 stable population mode 混同。
4. DDM 的 decision variable 当作直接观测 neuron。
5. 只拟合 psychometric，不检验 chronometric。
6. LIP correlation 直接等于 causal accumulator。
7. descriptive DDM 与 biophysical attractor model 混为同一层级。

  Course‑specific risk boundary. 区分 working‑memory content、neural correlate、persistent
  mode 与 synaptic memory；区分 descriptive DDM 与 biophysical attractor model。
