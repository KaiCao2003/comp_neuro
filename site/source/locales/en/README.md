# English locale source

The English teaching text in this directory is authored directly by Codex from the canonical Chinese records in `source/self-study/`, `source/figures/`, and `content/lectures/`.

Do not generate or revise these files with Google Translate, Bing/Microsoft Translator, a web translation endpoint, or a local machine-translation model. Translate against the Chinese source itself and review the result as computational-neuroscience teaching prose.

The following fields are structural and must remain identical to the Chinese edition: IDs, ordering, source filenames/pages, source references, LaTeX, formula expressions, figure geometry, and Chinese glossary terms. Numeric tokens and protected scientific symbols are checked during `npm run validate`.
